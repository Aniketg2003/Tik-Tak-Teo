# ❌ ⭕ Tic-Tac-Toe Game

A classic, interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## 🌐 Live Demo
Play the game here: **[https://tictaktoeaniket.netlify.app/]**

## 📖 About The Project
This project is a digital version of the paper-and-pencil game for two players, X and O, who take turns marking the spaces in a 3×3 grid. The player who succeeds in placing three of their marks in a horizontal, vertical, or diagonal row is the winner.

## 📂 Project Structure
Based on the repository files:

* **`index.html`**: The main structure of the game board.
* **`tik.css`**: Handles the styling, grid layout, and visual design.
* **`tiktak.js`**: Contains the game logic (handling clicks, switching turns, and checking for a winner).

## 🛠️ Technologies Used
* **HTML5**
* **CSS3**
* **JavaScript**

## 🎮 How to Play
1.  Open the game in your browser.
2.  Player **X** starts first.
3.  Click on any empty box in the grid to place your mark.
4.  The turn switches to Player **O**.
5.  The first player to get 3 marks in a row (up, down, across, or diagonally) wins!
6.  If all 9 squares are full and no one has won, it's a Draw.
